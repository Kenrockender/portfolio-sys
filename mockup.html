§ 04WHAT IT KNOWS / KEMAMPUAN
portfolio.sys --track
NAME
Lacak posisi multi-aset secara real-time
SYNOPSIS
--track [stocks|crypto|gold|p2p|deposit|fund|...]
DESC
Saham IDX, kripto, emas, reksa dana, P2P, deposito, properti, dan custom. Tidak ada batasan kategori.
SOURCES
IDX · Stockbit · Bibit · Pluang · Binance · Pintu · Tokocrypto
portfolio.sys --analyze
NAME
Analisis risiko & diversifikasi otomatis
SYNOPSIS
--analyze --risk --sharpe --drawdown
DESC
Volatility, Sharpe, max drawdown, korelasi antar-aset. Diversifikasi diukur, bukan ditebak.
SCOPE
Per-aset · Per-kategori · Total portofolio
portfolio.sys --rebalance
NAME
Rebalance saran berbasis target
SYNOPSIS
--rebalance --target=conservative|balanced|aggressive
DESC
Bandingkan komposisi sekarang dengan target Anda. Saran beli/jual yang spesifik, dengan estimasi biaya transaksi.
FREQ
Manual · Mingguan · Bulanan · Kuartalan
portfolio.sys --tax
NAME
Lacak pajak realized & unrealized
SYNOPSIS
--tax --year=2026 --jurisdiction=ID
DESC
Hitung PPh atas dividen, capital gain, dan transaksi efek. Export ke format SPT.
JURIS
Indonesia (PPh Final 0,1%) · Custom rules
portfolio.sys --ml
NAME
Model ML untuk deteksi pola
SYNOPSIS
--ml --predict --regime --anomaly
DESC
Regime detection, anomaly flagging, prediksi rentang harga 1–30 hari. Output dengan confidence interval, bukan klaim ramalan.
MODELS
LSTM · ARIMA · Isolation Forest · Custom
portfolio.sys --ai
NAME
Tanya AI tentang portofolio Anda
SYNOPSIS
--ai "kenapa BBCA turun minggu ini?"
DESC
Powered by Gemini. Memahami posisi Anda, membaca berita, menjawab dalam Bahasa. Tidak ada saran beli/jual.
PRIVACY
Data Anda tidak dipakai untuk training. LOCAL ONLY
